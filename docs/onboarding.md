# OEM onboarding

- Provide your GitHub username(s) to your NVIDIA contact
- You'll receive a collaborator invite to `NVIDIA-Omniverse/simready-central`
- Accept the invite to gain push and pull request permissions

After onboarding is complete, follow the
[OEM asset submission guide](oem-asset-submission-guide.md), and the checks it
must pass in [Acceptance criteria](acceptance-criteria.md).
